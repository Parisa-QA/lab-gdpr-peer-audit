## Project overview

This repository contains an independent EU AI Act and GDPR peer audit of Louise Plessis’s Project 3, an AI-powered entertainment agent that generates episode-aware Love Is Blind recaps using public web sources, YouTube comments, OpenAI and Pinecone retrieval.

## Audit outcome

The system is currently a closed prototype. Its provisional classification for a future EU deployment is **limited risk / transparency**.

The overall recommendation is **Proceed with conditions**. Before an EU production launch, the project should address Article 50 transparency, GDPR data governance, vendor and transfer safeguards, retention and deletion, data-subject rights, correction mechanisms and spoiler-check failure handling.

## Important limitation

This peer audit is an educational first-pass assessment. It is not legal advice, a conformity assessment or a certification.
